# Demo Video Recording Checklist

## Recording Setup
- [ ] Screen resolution set to 1920x1080 or higher
- [ ] Browser zoom set to 100%
- [ ] Terminal font readable
- [ ] Microphone level checked
- [ ] Notification popups disabled

## Pre-Demo Data Prep
- [ ] PostgreSQL running
- [ ] App deployed and accessible
- [ ] At least 3 sample products available
- [ ] One normal user account available
- [ ] Admin account available

## Mandatory Scenes
- [ ] Intro + architecture mention
- [ ] Build/package command shown
- [ ] Register/login shown
- [ ] Browse/search/add-to-cart shown
- [ ] Checkout + payment via RMI shown
- [ ] Order history + invoice shown
- [ ] Admin analytics shown
- [ ] Admin user role update shown
- [ ] Admin product add/delete shown
- [ ] Verify command result shown

## Final Export
- [ ] MP4 format
- [ ] Duration between 6 and 8 minutes
- [ ] Audio clear and consistent
- [ ] Filename: `Distributed-Ecommerce-Demo.mp4`
